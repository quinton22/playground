# thinking of u 💕

A fun, private way to let people know you're thinking of them.

## How it works

1. **Add up to 3 people** — enter the phone number of someone you're thinking of each day.
2. **Mutual match required** — if they _also_ added your phone number the same day, it's a match!
3. **Both get notified** — you'll both receive a push notification saying the other was thinking of you.
4. **Resets daily** — unmatched submissions reset at midnight UTC (unless you have extension days).

## Features

- 🔒 **Privacy first** — phone numbers are hashed (SHA-256) before storage; never stored in plaintext.
- 💌 **3 daily sends** — each user gets 3 "thinking of u" sends per day by default.
- ⏳ **Extensions** — purchase extension days to keep unreciprocated sends alive longer.
- 🛒 **In-app store** — buy extra sends (up to 10/day) and extension days.
- 📊 **Match history** — see all your past matches and streaks.
- 🔔 **Push notifications** — instant notification when a mutual match is detected.

## Feature flags

Edit `lib/config/feature_flags.dart` to toggle optional features:

| Flag | Default | Description |
|------|---------|-------------|
| `enableHistoryScreen` | `true` | Show past match history |
| `enableStreakTracking` | `true` | Track consecutive match-day streaks |
| `enableSocialSharing` | `false` | Invite friends via share link |
| `enableLuckyGuess` | `false` | One daily hint about a potential match |
| `enableAnalytics` | `true` | Firebase Analytics tracking |
| `enableInAppPurchases` | `true` | Store with extra sends & extensions |

## Setup

### Prerequisites

- [Flutter SDK](https://flutter.dev/docs/get-started/install) ≥ 3.13
- [Firebase CLI](https://firebase.google.com/docs/cli)
- A Firebase project with the following enabled:
  - Authentication → Phone
  - Firestore Database
  - Cloud Functions
  - Cloud Messaging (FCM)

### 1. Create a Firebase project

```bash
firebase login
firebase projects:create thinking-of-u
```

### 2. Configure Firebase for Flutter

```bash
dart pub global activate flutterfire_cli
flutterfire configure --project=YOUR_PROJECT_ID
```

This auto-generates `lib/firebase_options.dart` with your real credentials.

### 3. Deploy Firestore rules and indexes

```bash
firebase deploy --only firestore
```

### 4. Deploy Cloud Functions

```bash
cd functions
npm install
npm run build
cd ..
firebase deploy --only functions
```

### 5. Set up in-app purchases

In the App Store Connect and Google Play Console, create the following products:

| Product ID | Type | Description |
|------------|------|-------------|
| `thinking_of_u_extra_send_1` | Consumable | +1 extra send today |
| `thinking_of_u_extra_send_3` | Consumable | +3 extra sends today |
| `thinking_of_u_extension_1day` | Consumable | +1 day extension |
| `thinking_of_u_extension_3days` | Consumable | +3 day extension bundle |

### 6. Run the app

```bash
flutter pub get
flutter run
```

## Security model

| Data | Storage method |
|------|----------------|
| Phone numbers | SHA-256 hash only — never stored in plaintext |
| Display names | First name only, visible to matched users via Cloud Functions |
| Submissions | Encrypted Firestore, readable only by owner |
| Matches | Written only by Cloud Functions (admin SDK) |
| FCM tokens | Stored per-user, used only to deliver notifications |

Firestore security rules enforce that:
- Users can only read/write their own documents
- Match records are written exclusively by Cloud Functions
- Purchase records are written exclusively by Cloud Functions

## Architecture

```
lib/
├── main.dart               — App entry point
├── app.dart                — Root widget with service/BLoC providers
├── router.dart             — go_router navigation
├── firebase_options.dart   — Firebase config (auto-generated by flutterfire)
├── config/
│   └── feature_flags.dart  — Feature toggle constants
├── blocs/
│   ├── auth/               — Phone auth state management
│   └── home/               — Home screen state management
├── models/                 — Data models (UserModel, SubmissionModel, etc.)
├── screens/                — All app screens
├── services/               — Firebase service wrappers
├── theme/                  — Colors and ThemeData
├── utils/                  — Phone/crypto utilities
└── widgets/                — Reusable UI components

functions/
└── src/index.ts            — Cloud Functions (matching, daily reset, etc.)

firestore.rules             — Firestore security rules
firestore.indexes.json      — Firestore composite indexes
firebase.json               — Firebase project config
```

## Cloud Functions

| Function | Trigger | Description |
|----------|---------|-------------|
| `onSubmissionWritten` | Firestore write | Checks for mutual matches, sends notifications |
| `dailyReset` | Cron (midnight UTC) | Resets daily send counts, decrements extensions |
| `getUserDisplayName` | HTTPS Callable | Safely looks up a user's display name by phone hash |

## Local development with emulators

```bash
firebase emulators:start
```

Then in your app, connect to the emulators by adding the following to `main.dart`:

```dart
if (kDebugMode) {
  FirebaseFirestore.instance.useFirestoreEmulator('localhost', 8080);
  FirebaseAuth.instance.useAuthEmulator('localhost', 9099);
  FirebaseFunctions.instance.useFunctionsEmulator('localhost', 5001);
}
```
